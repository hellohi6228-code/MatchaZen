# Matcha Zen · The Ritual of Cha

Pre-launch website for **Matcha Zen**, a NOMIX Hospitality brand opening December 2026 in Houston, TX.
Drinks · Gelato · Gelato Cakes · Bakery. 100% organic matcha.

Static site (HTML/CSS/JS, no build step) hosted on GitHub Pages.

- Change the opening countdown target in `js/main.js` (`OPEN_DATE`).
- Brand palette lives at the top of `css/style.css` (from the brand deck's Visual Identity page).
- Photos are in `assets/img/`.
